# Data And Persistence Checklist

- Entities, records, aggregates, relationships, ownership, lifecycle, retention,
  deletion, export, audit, and data classification.
- Database indexes, uniqueness, constraints/foreign keys or equivalents,
  partitioning, pagination, sorting, filtering, and performance budgets.
- Query patterns and schema guidance traced to current database/ORM/provider
  documentation or approved research.
- Transactions, consistency, idempotency, concurrency, locking, conflict
  resolution, validation, and no-data-loss behavior.
- Migrations, backfills, rollback, recovery, manual intervention, and final
  state.
