# Structure Checklist Index

Load these detailed checklists for every spec set:

- `checklist-architecture-structure.md`: file/folder structure, ownership,
  generated outputs, public entrypoints, reusable module placement.
- `checklist-contracts-generation.md`: source contracts, generators, strict
  boundary typing, compatibility.

Also load `checklist-service-topology.md` when the app has more than one
runtime, service, package, deployable, worker, client/server boundary, or
integration boundary.
