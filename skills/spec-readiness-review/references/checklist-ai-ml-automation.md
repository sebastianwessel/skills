# AI, ML, And Automation Checklist

- Define automation scope, model/provider/version, current docs, fallback,
  latency/cost budgets, tools/actions, human approval, prompt ownership,
  retrieval/index sources, grounding, citations, memory, and retention.
- Specify safety policy, blocked content, sensitive data handling,
  hallucination/error handling, uncertainty display, overrides, audit, evals,
  golden datasets, quality metrics, monitoring, drift, rollback, and outage.
- Test unsafe input, prompt injection, missing/stale context, wrong tool call,
  private data leak, low confidence, and provider error.
