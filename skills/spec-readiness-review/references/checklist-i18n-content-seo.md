# Internationalization, Content, And SEO Checklist

- Define locales, fallback, ownership, pluralization, formatting, RTL,
  collation, date/time, timezone, currency, units, negotiation, and layout
  expansion.
- Specify user/editorial/legal/support/error copy, moderation, lifecycle,
  privacy-safe wording, public routes, metadata, canonical URLs, robots/sitemap,
  structured data, redirects, and crawl rules.
- Test missing translation, long text, RTL, timezone boundaries, currency
  precision, metadata, redirects, and noindex/canonical behavior.
