# Runtime And Platform Checklist

- Define language/runtime, package manager, build tools, framework/compiler
  versions, current stable defaults, and supported OS/browser/device/hosting
  targets.
- Specify environment names, config schema, env vars, validation, local
  defaults, forbidden production fallbacks, and reproducible setup checks.
- Cover compatibility with databases, queues, storage, browser APIs, SDKs,
  CLIs, plugins, CI/CD runners, and generated artifact commands.
