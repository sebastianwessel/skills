# Security And Abuse Checklist

- Define threat model, trust boundaries, actors, attack surfaces, privileged
  paths, data classification, and out-of-scope risks.
- Cover validation/encoding and common web/request risks: injection, XSS, CSRF,
  CORS/CSP, SSRF, traversal, deserialization, file handling, replay, brute
  force, enumeration, abuse, fraud, bots, and rate limits.
- Require safeguards and tests for dangerous actions, authorization rechecks,
  audit events, rollback/compensation, scanners, and high-risk manual review.
