# Import, Export, And Sync Checklist

- Define import/export sources, destinations, formats, schemas, mappings,
  validation, preview/dry-run, dedupe, conflicts, bulk sizes, batching, progress,
  cancellation, retries, partial failure, and final state.
- Specify sync direction, source of truth, triggers, checkpoints, replay,
  tombstones, drift repair, portability, audit, privacy, redaction, access, and
  manual intervention.
- Test malformed data, duplicates, partial success, permission denial,
  interrupted sync, conflicts, deleted remote object, large file, and re-run.
