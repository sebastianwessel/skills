# Search, Reporting, And Analytics Checklist

- Define search fields, filters, facets, sorting/ranking, pagination,
  permissions, tenant isolation, empty states, index source, freshness, rebuilds,
  backfills, deletion propagation, and consistency.
- Specify reports, dashboards, metric definitions, aggregation windows,
  timezones, export formats, reconciliation, analytics schema, consent,
  privacy, retention, sampling, and ownership.
- Test permission-filtered search, stale/deleted data, large export, metric
  accuracy, timezone edges, consent denial, and backfill/rebuild.
