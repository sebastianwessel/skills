# Notifications And Communications Checklist

- Define channels, triggers, templates, localization, personalization, safe
  copy, preferences, opt-out/consent, quiet hours, and rate limits.
- Specify provider current docs/API version, credentials, sender identity,
  deliverability, bounces/complaints, suppression, retries, ordering,
  idempotency, status, audit, redaction, and support.
- Test success, provider failure, invalid destination, opt-out, duplicate
  trigger, retry exhaustion, template error, and privacy leak.
