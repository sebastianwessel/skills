# Secrets And Privacy Checklist

- Credentials, tokens, API keys, private keys, certificates, cookies, and secret
  classification.
- Secure storage, encryption/hashing, rotation, revocation, expiration, scoping,
  least privilege, injection, local defaults, and CI/CD exposure.
- Logs, metrics, traces, errors, screenshots, exports, support tools, generated
  artifacts, and tests leak no secrets, credentials, PII, or sensitive data.
- Privacy rules for consent, retention, deletion, access, export, masking,
  redaction, residency, and audit.
- Incident, recovery, and manual intervention paths for leaked or revoked
  credentials.
