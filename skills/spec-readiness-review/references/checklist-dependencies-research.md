# Dependencies And Research Checklist

- Current stable versions for dependencies, databases, frameworks, cloud
  services, protocols, SDKs, drivers, and third-party solutions.
- Primary documentation, package metadata, release metadata, changelog or release
  notes, and retrieval date for each relevant third-party choice.
- Dated research evidence for state-of-the-art choices when multiple viable
  solutions exist, including alternatives and rejected options.
- Official docs used for schema design, indexes, query patterns, performance
  guidance, security setup, configuration, operational limits, migrations, and
  generated artifacts.
- Older pins or nonstandard choices justified by compatibility, migration,
  security, licensing, performance, or support constraints.
- Blocker when current docs cannot be checked and implementation would otherwise
  rely on model memory.
