# Operations, Release, And Supply Chain Checklist

- Log levels, audit events, metrics, traces, correlation IDs, redaction,
  alerting, dashboards, SLO/SLA/error budgets, runbooks, ownership, support
  handoff, and incidents.
- Readiness/liveness, config validation, feature flags, operational limits,
  safe defaults, backup/restore, and manual intervention.
- Rollout, rollback, compatibility, versioning, migrations, backfills, release
  gates, cleanup, no-leak/no-data-loss, old-boundary compatibility, stale alias
  deprecation, and migration history.
- Dependency policy, lockfiles, vulnerability/license checks, SBOM, provenance,
  signing, container/base image policy, artifact ownership, secret scanning,
  pinned generators/tools, reproducibility, and release artifact verification.
