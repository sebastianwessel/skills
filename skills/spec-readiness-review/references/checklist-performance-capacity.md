# Performance And Capacity Checklist

- Define latency, throughput, concurrency, memory, CPU, storage, network,
  realtime, batch, queue-depth, provider, and cost budgets.
- Specify cache strategy, keys, invalidation, freshness, stale reads, warmup,
  eviction, ownership, pagination, batching, streaming, and backpressure.
- Cover volumes, growth, quotas, rate/timeout/retry budgets, overload
  behavior, graceful degradation, load tests, regression checks, and monitoring.
