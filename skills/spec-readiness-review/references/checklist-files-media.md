# Files And Media Checklist

- Define upload/download/preview/delete/share/transform/scan/transcode/capture,
  storage provider, object layout, metadata, MIME/type, size, quotas, lifecycle,
  CDN/cache, and retention.
- Specify access control, signed URLs, tenant isolation, visibility, malware or
  moderation checks, redaction, leak prevention, processing jobs, cleanup, and
  recovery/final state.
- Test invalid type, oversized file, denied access, expired URL, duplicate
  upload, failed transform/scan, deletion, and restore.
