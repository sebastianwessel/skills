# Core Checklist

- Scope: domains/topics, actors, clients, consumers, entrypoints, public
  surfaces, and explicit N/A layers.
- Capability inventory: user, admin, API/CLI/SDK, integration, worker/job, data
  lifecycle, and operational capabilities or explicit N/A categories.
- Traceability: source specs for behavior, contracts, NFRs, acceptance rows, and
  verification.
- Drift risk: decisions tickets must not make, forbidden interpretations, and
  source-of-truth links.
- Completeness: happy paths, unhappy paths, recovery, final states, and
  verification evidence for each relevant business outcome.
- Ownership: requirement owner, implementation owner, operational owner, and
  review owner when relevant.
