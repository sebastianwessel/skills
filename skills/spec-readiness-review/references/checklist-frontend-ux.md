# Frontend, UX, And Accessibility Checklist

- Access paths, screens/surfaces, navigation, loading, empty, error, success,
  denied, offline, permission, and recovery states.
- Accessibility, keyboard/focus behavior, responsiveness, localization, safe
  copy, and privacy-safe UI messages.
- Design source, design system, component library, shared styles/tokens,
  reusable components/modules, and custom UI rationale.
- Client-side auth, permissions, data freshness, optimistic updates, retries,
  cache invalidation, and error recovery.
- Browser/client tests, accessibility checks, visual states, and responsive
  verification when relevant.
